1. Product Overview

1.1 Vision

Xanda Cross is an AI-powered unified communication platform that consolidates all of a user's messages from every major platform — Gmail, Outlook, WhatsApp, LinkedIn, Instagram, Telegram, and Slack — into a single intelligent inbox. The platform is powered by an AI assistant named Xan, who understands conversation context, ranks messages by priority, labels conversations by topic, generates message summaries, drafts replies, and surfaces connections across platforms that the user would otherwise miss.

The core insight: professionals split their communication lives across 5–7 apps simultaneously. Context is lost constantly. Xanda Cross solves this not by being another aggregator, but by being the first truly intelligent inbox — where the AI does the heavy lifting so the user only focuses on decisions, not on reading and sorting.

2. Problem Statement

Professionals today manage 5–7 communication apps simultaneously. Every time they switch apps, context is lost. A deal discussed on WhatsApp, followed up on email, and confirmed on LinkedIn exists in three separate silos with no link between them.

Existing tools fail in three ways:

1. Aggregators without intelligence — show all messages together but don't help you decide what matters

2. AI assistants with no real integration — can talk about email but cannot actually read it

3. Single-channel tools — Superhuman only does Gmail; nothing covers 7 platforms

Xanda Cross solves all three simultaneously: aggregation (all channels, one place) + intelligence (AI that understands what matters) + context (cross-platform relationship awareness).

3. Core Features

Feature 1

Time-Aware Personalised Briefing Screen

The first screen a logged-in user sees. Greets the user by first name. Adapts dynamically based on time of day and actual inbox state.

Empty inbox"You're all caught up. Nothing needs your attention right now."
Active, no new"No new messages, but you have [N] active conversations in progress."

Persistent element: Search bar always visible at bottom. Placeholder: "Ask Xan anything or search across all conversations..."

Feature 2

Unified Inbox

A single feed showing all messages from all connected platforms, ranked by AI priority — not by time received.

Each conversation row displays:

  • Contact profile photo (circular avatar)
  • Contact full name in bold
  • Platform icon (16px, official brand colour) after the name
  • AI topic label — Engineering Hiring Term Sheet Payment Follow-up — pill-shaped, teal, auto-assigned by Xan
  • Message preview text (single line, muted, truncated)
  • Timestamp + unread indicator
  • Priority left-border: red (High) / amber (Medium) / grey (Low)
Feature 3

AI Priority Ranking

Every incoming message is scored by Xan and assigned: High Medium Low

Xan scores based on: Sender relationship strength · Message keywords (urgent, invoice, contract, deadline) · Response required (NLP detection) · Thread age · Sender importance · Time sensitivity

Priority is recomputed every time a new message arrives in a thread.

Feature 4

AI Message Headline

Every message gets a one-line AI-generated summary by Xan. Appears in the inbox row. User understands the message without opening it.

Examples: "Rohan asking for a call today re: term sheet" · "Sara confirmed the deal — needs invoice by Friday" · "Candidate accepted offer — needs joining date"

Feature 5

AI Auto-Drafted Reply

Every message gets a pre-drafted reply written by Xan, ready when the user opens the conversation. User edits if needed and sends. Nothing is ever sent automatically.

Xan drafts based on: full conversation history · user's writing style from past sent messages · context and tone of the relationship

Feature 6

Auto-Labelled Topics

Xan reads full conversation context and automatically assigns a 2–4 word topic label to every conversation. No manual tagging. Labels appear as teal pills in the inbox.

Feature 7

Universal Semantic Search

Search across all conversations from all platforms using natural language. Powered by vector embeddings in PostgreSQL via pgvector. Finds messages by meaning, not just keywords.

Examples: "emails about Series A from Sequoia" · "everything Rohan said about the launch date" · "WhatsApp messages about pricing in the last 30 days"

Feature 8

Contextual Cross-Platform Linking

Xan proactively identifies when messages across different platforms are about the same topic or deal and surfaces them together inside the conversation view.

Example: A contract sent on WhatsApp on Monday + a Gmail email Tuesday requesting that contract → Xan surfaces both together automatically.

Feature 9

Smart Contact Profiles

Every contact has a unified profile page showing: cross-platform conversation history · active topics · open goals · relationship timeline · last interaction date and channel · Xan-computed relationship health score.

Feature 10

@Xan Mentions

Users can type @Xan anywhere in the platform to ask questions, request summaries, search conversations, or get briefings.

Examples: "Summarise my conversation with Rohan" · "What's the status of the Acme deal?" · "Who haven't I replied to in 3 days?" · "Give me a briefing on everything I missed today"

Xan responds in short, structured format — lists and direct answers, never long paragraphs.

5. AI Architecture — Xan

5.1 Xan's Four Automatic Jobs (per message)

All four run as background BullMQ jobs immediately after a message is stored. Results pushed to browser via WebSocket within 2–5 seconds.

JobModelOutput
generate-headlineGPT-4o-miniOne-line message summary
score-priorityGPT-4o-miniHigh / Medium / Low + reasoning
assign-topic-labelGPT-4o-mini2–4 word topic label
draft-replyGPT-4oFull draft reply in user's tone

5.2 AI Models

PurposeModelWhy
Headline, priority, labelGPT-4o-miniFast, cheap, high quality for short outputs
Reply draftingGPT-4oHigher quality writing; worth the cost
Structured outputZod + function callingNever parse free-form LLM text
Embeddingstext-embedding-3-small$0.02/1M tokens; 1536 dimensions
Semantic searchpgvector (PostgreSQL)No extra DB needed for MVP
Long context (Phase 2)Claude 3.5200k context for full inbox analysis

5.3 Message Processing Pipeline

Webhook arrives (Unipile or Slack) ↓ API server receives → validates signature ↓ Message normalised to CanonicalMessage schema ↓ Stored in PostgreSQL ↓ Contact resolved / created ↓ Four BullMQ jobs dispatched in parallel: ├── generate-headline → GPT-4o-mini → saved to DB ├── score-priority → GPT-4o-mini → saved to DB ├── assign-topic-label → GPT-4o-mini → saved to DB └── draft-reply → GPT-4o → saved to DB ↓ Embedding job: text-embedding-3-small → pgvector ↓ Socket.io pushes update to browser ↓ Inbox updates live with all AI outputs

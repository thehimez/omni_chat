# IMPLEMENTATION TASK — Replace Current Priority System with AI Action Inbox

The current Priority/Briefing page is not useful because it is based mainly on unread messages, recency, and simple scoring.

I want to completely redesign the system into an **AI Action Inbox**.

This should behave like a personal executive assistant that continuously monitors all incoming messages and surfaces only conversations that require action from me.

---

## CORE PHILOSOPHY

The briefing page should NOT answer:

```text
What is unread?
```

The briefing page should answer:

```text
What do I need to do right now?
```

This is a fundamentally different system.

Unread messages ≠ Important.

Important means:

* Someone is waiting for my response
* Someone requested something from me
* Someone asked a question
* Someone wants a decision
* Someone wants approval
* Someone wants information
* Someone assigned me work
* Someone invited me to something
* Someone expects an action

Everything else should be ignored.

## CONNECTED APP FILTERING FEATURE (VERY IMPORTANT)

Implement dynamic inbox filtering based on the connected app icons visible in the left sidebar.

Behavior requirements:

1. ONLY connected apps should appear in the left sidebar icon dock.

Example:
If the user connected:

* Gmail
* WhatsApp
* Telegram

Then ONLY these 3 icons should appear.

2. When user clicks a connected app icon:
   The inbox should instantly filter and display ONLY messages from that specific platform.

Examples:

* Clicking Gmail icon → show only Gmail conversations/messages
* Clicking WhatsApp icon → show only WhatsApp chats
* Clicking Telegram icon → show only Telegram conversations

3. Add active selection states:

* Selected platform icon should have:

  * soft blue glow
  * elevated background
  * subtle shadow
  * smooth animation

4. Add “Unified Inbox” mode:
   When user clicks Unified Inbox:

* combine all messages from all connected apps
* show all platforms together in one stream

5. Message cards should always show the originating platform icon on the right side.

Example:

* Gmail icon for email
* Telegram icon for Telegram message
* WhatsApp icon for WhatsApp message

6. Filtering should happen instantly without page reload.

7. Use smooth transitions when switching between app filters.

8. Maintain scroll position and responsive performance even with large datasets.

9. This filtering system should feel exactly like the reference UI provided.

The experience should feel:

* seamless
* modern
* native
* smooth
* premium

This feature is a CORE part of the product experience.

Core features to build:

Time-aware home screen — greets user by name with dynamic greeting based on time of day (Good morning / afternoon / evening / night). Shows count of new and active messages. If inbox is empty shows a calm "you're all caught up" message. Has a search bar to ask @Xan anything.
Unified inbox — all messages from all platforms in one feed, ranked by AI priority score (High / Medium / Low) not by time received. Each message row shows: contact photo, name, platform icon, AI-generated topic label (pill shaped, coloured), and message preview.
AI priority ranking — every incoming message is scored by Xan based on sender relationship, keywords, urgency, and context. Inbox always shows highest priority first.
AI message headline — every message gets a one-line summary generated by Xan so user understands it without opening it.
AI auto-drafted reply — every message gets a pre-drafted reply by Xan based on full conversation history and user's writing style. User sees the draft when they open the message, edits if needed, and sends. Nothing is ever sent automatically.
Auto-labelled topics — Xan reads conversation context across all platforms and automatically assigns a short topic label (2–4 words) to every message. No manual tagging needed.
Universal semantic search — user can search across all conversations using natural language. Powered by vector embeddings stored in pgvector. Finds messages by meaning not just exact keywords.
Contextual assistant — Xan proactively links related messages across platforms. If a contract was sent on WhatsApp and an email requesting it exists in Gmail, Xan surfaces both together automatically inside the conversation view.
Smart contacts — every contact has a profile showing full cross-platform conversation history, open topics, active goals, and relationship timeline.
@Xan mentions — user can type @Xan anywhere in the platform to ask questions, request summaries, search conversations, or get briefings.

Authentication and access control:

Clerk handles all authentication
New users start in a pending state by default
Admin panel allows manual activation of specific users (for internal team testing)
Payment via Stripe automatically activates accounts
Unipile white-label auth hosted on a custom subdomain (auth.xandacross.com) so users never see Unipile branding
